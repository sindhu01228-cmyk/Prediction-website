PROJECT INFORMATION

About AcadMetrics

Modelling Student Academic Performance

This project studies how study hours, attendance, sleep duration and previous exam scores relate to final academic marks. It uses descriptive statistics, Pearson correlation, simple linear regression and multiple linear regression.
