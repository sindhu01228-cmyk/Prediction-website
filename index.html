Python Implementation

# Simple Linear Regression — Python (scikit-learn) import pandas as pd from sklearn.linear_model import LinearRegression df = pd.read_csv("student_performance.csv") # n = 60 X = df[["study_hours"]]; y = df["final_marks"] model = LinearRegression().fit(X, y) print(f"ŷ = {model.intercept_:.1f} + {model.coef_[0]:.2f}·X") print(f"R² = {model.score(X,y):.3f}") # 0.672

Conclusion & Future Scope

The study confirms that academic performance is strongly associated with study habits. Multiple regression provides a reliable, interpretable tool for early identification of at-risk students.

✓

Strong Correlation

Study hours ↔ Final marks r = 0.82 (strong positive). Attendance & prev performance support the relationship.

◎

Best Influential Factor

Study hours is the most influential factor, followed by attendance and previous exam score.

⬢

Reliable Prediction

Multiple model R² = 0.724, RMSE = 3.76 — good accuracy for educational interventions.

Limitations

  • Sample size 60 — larger cohort would improve generalisation
  • Self-reported study/sleep hours may have bias
  • Unmeasured factors: motivation, teaching quality, distractions
  • Linear assumption — non-linear effects not modelled

Future Scope

  • Machine learning: Random Forest, XGBoost, Neural Nets
  • Add variables: screen time, stress, socio-economic status
  • Real-time dashboard with MongoDB & live Python API
  • Early-warning system for at-risk students
